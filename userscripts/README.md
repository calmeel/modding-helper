# Modding Helper Userscript

Adds a **modding helper** button to osu! beatmapset pages to open all taiko difficulties in Modding Helper in a new tab.

## Installation

1. Install [Tampermonkey](https://www.tampermonkey.net/).
2. Install [the userscript](https://calmeel.github.io/modding-helper/userscripts/modding-helper.user.js).

## Notes

- Only taiko `.osu` files are loaded.
- Audio, BG images, videos, and other assets are not fetched.
- Original file and folder names are unavailable, so file and folder name checks are skipped.
