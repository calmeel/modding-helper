実装上のメモ
  • 検出フィールドが Artist の場合は Artist / ArtistUnicode、Title の場合は Title / TitleUnicode の両方を検出しています。
  • 大文字・小文字の違いは基本的に吸収されます。
  • Ado / NOMA / Avans / Zekk / tyDi / lapix / Frums / ak+q / iL は、キーワードの直前・直後に半角英数字がある場合は検出しません。それ以外は部分一致で検出します。
