osu!taikoのスピナー（Swell／風船）は、osu!stableとosu!lazerで必要打数の計算と完了条件が異なります。 特にstableでは、計算結果の最低値が1でも、実際に割るには中央打・縁打を交互に2回入力する必要があります。 このページでは、ODと長さから求める基礎値、整数化の順序、最低入力数、入力判定を分けて整理します。

3. ODから求める基礎速度

両クライアントの基礎となる速度は、ODに応じて3から7.5まで変化します。

OD < 5:
    R(OD) = 5 - 2 × (5 - OD) / 5

OD = 5:
    R(OD) = 5

OD > 5:
    R(OD) = 5 + 2.5 × (OD - 5) / 5
OD 03.0 /秒
OD 55.0 /秒
OD 107.5 /秒

Taikoでは、この基礎値へlegacy由来の1.65倍が適用されます。ただし、stableとlazerでは整数化する位置が異なります。

4. osu!stableの必要打数

stable 1先に基礎half-spin数を整数化

Hbase = trunc(D / 1000 × R(OD))

Hstable = trunc(max(1, Hbase × 1.65))

truncは0方向への切り捨てです。長さとODから得た値を一度整数へ落としてから1.65倍するため、lazerのように全要素を掛けてから最後に切り捨てる式とは一致しません。

stable 2閾値を越える最後の1打

Hstableは実入力数そのものではなく、完了判定の閾値です。進行値がこの閾値を越えるまで入力が必要です。

Nstable = Hstable + 1

lazerのstable互換スコア計算でも、次の包含ループとして再現されています。

for (i = 0; i <= Hstable; i++):
    SwellTickを1個加算

生成数 = Hstable + 1
最低2打になる理由：Hstableの最低値は1ですが、入力は0回目と1回目の2回が必要です。そのため、中央打1回または縁打1回だけでは割れず、中央→縁または縁→中央の2入力で完了します。

5. osu!lazerの必要打数

lazerはOD、長さ、1.65をまとめて掛け、最後に1回だけ整数化します。

hitsPerSecond = R(OD) × 1.65

Nlazer = trunc(max(1,
                   D / 1000 × hitsPerSecond))

SwellはNlazer個のSwellTickを生成します。有効な入力1回につき未判定のSwellTickを1個成功させ、成功数がRequiredHitsと等しくなった時点で完了します。

入力ごとに:
    次のSwellTickを成功させる
    numHits = 成功したSwellTick数

    if numHits == RequiredHits:
        スピナー完了
lazerでは本当に最低1打：公式テストにはRequiredHits = 1のTaiko SwellへLeftRimを1回入力し、LargeBonusで完了するケースがあります。これはosu!standardのスピナーテストではありません。

6. 中央打・縁打の交互入力

通常プレイでは、両クライアントとも同じ種類を連続入力するだけでは進みません。必要なのは左右交互ではなく、中央打と縁打の交互入力です。

有効:
    中央 → 縁 → 中央 → 縁 ...
    縁 → 中央 → 縁 → 中央 ...

無効になる連続入力:
    中央 → 中央
    縁 → 縁

lazerのDrawableSwellは直前の入力が中央だったかを保持し、同じ種類が続いた場合はSwellTickを進めません。Relaxではこの交互制限が解除されます。

キー名について：どの物理キーが中央・縁になるかはキーバインド次第です。「dk / kd」が有効という説明は、それぞれが中央・縁へ割り当てられている場合に対応します。

stableの必要half-spin閾値には速度変更Modによる倍率もあり、公式のlegacy互換コードではDT = 0.75、HT = 1.5と説明されています。本ページの表はNMを前提としており、プレビューの25%～150%再生はゲームModとは別の操作として扱います。

まとめ
osu!stableの最低値1は完了閾値であり、実際にはそれを越える2打目が必要です。
osu!lazerのRequiredHitsは実入力数そのもので、最低値1なら1打で完了します。
