osu!stable / osu!lazer Taiko Spinner Required Hit Calculation

This page is a technical reference for the Modding Helper documentation. For appearance timing, see Taiko Spinner Appearance Timing.

osu!taiko spinners (Swells / balloons) use different required-hit calculations and completion conditions in osu!stable and osu!lazer. In particular, even when stable's calculated minimum is 1, the spinner actually requires two alternating centre and rim inputs to be cleared. This page separately explains the base value derived from OD and duration, the order of integer conversion, the minimum number of inputs, and input validation.

1. Investigation and sources

osu!stable
Analysis of osu!.exe and lazer's stable-compatible logic

In osu!stable, a spinner completes when its progress value exceeds the required number of half-spins. lazer's legacy score simulation also reproduces this behaviour: after calculating stable's required value, it uses an inclusive i <= required loop to generate required + 1 SwellTicks.

2. Scope and terminology

Scope: this page covers only osu!taiko Swells (balloons / denden). Although they use spinner-type HitObjects in an .osu file, their gameplay and judgement classes are different from osu!standard's circular-motion spinners.

One input here means one centre or rim hit. The required alternation is between the centre and rim input types, not between the left and right sides.

3. Base rate derived from OD

The base rate used by both clients varies from 3 to 7.5 according to OD.

OD < 5:
    R(OD) = 5 - 2 × (5 - OD) / 5

OD = 5:
    R(OD) = 5

OD > 5:
    R(OD) = 5 + 2.5 × (OD - 5) / 5
OD 03.0 / second
OD 55.0 / second
OD 107.5 / second

Taiko applies the legacy-derived 1.65 multiplier to this base value. However, stable and lazer differ in where the value is converted to an integer.

4. osu!stable required hit count

stable 1Convert the base half-spin count first

Hbase = trunc(D / 1000 × R(OD))

Hstable = trunc(max(1, Hbase × 1.65))

trunc means truncation toward zero. Because the value derived from duration and OD is converted to an integer before the 1.65 multiplier is applied, this does not match lazer's calculation, which multiplies all factors before truncating once at the end.

stable 2The final hit that exceeds the threshold

Hstable is a completion threshold rather than the actual input count. Inputs must continue until the progress value exceeds that threshold.

Nstable = Hstable + 1

lazer's stable-compatible score simulation reproduces this with the following inclusive loop.

for (i = 0; i <= Hstable; i++):
    add one SwellTick

number generated = Hstable + 1
Why the minimum is two hits: the minimum value of Hstable is 1, but this requires input number 0 and input number 1. A single centre or rim hit therefore cannot clear the spinner; it completes after centre → rim or rim → centre.

5. osu!lazer required hit count

lazer multiplies OD, duration, and 1.65 together, then performs a single integer conversion at the end.

hitsPerSecond = R(OD) × 1.65

Nlazer = trunc(max(1,
                   D / 1000 × hitsPerSecond))

Swell generates Nlazer SwellTicks. Each valid input completes one unjudged SwellTick, and the spinner completes when the number of successful ticks equals RequiredHits.

for each input:
    complete the next SwellTick
    numHits = number of successful SwellTicks

    if numHits == RequiredHits:
        complete the spinner
lazer really does have a one-hit minimum: the official tests include a Taiko Swell with RequiredHits = 1 that receives one LeftRim input and completes with LargeBonus. This is not an osu!standard spinner test.

6. Alternating centre and rim inputs

During normal play, neither client advances the spinner when the same input type is repeated. The required alternation is not left and right; it is centre and rim.

Valid:
    centre → rim → centre → rim ...
    rim → centre → rim → centre ...

Invalid consecutive inputs:
    centre → centre
    rim → rim

lazer's DrawableSwell remembers whether the previous input was a centre hit and does not advance a SwellTick when the same type is repeated. Relax removes this alternating-input restriction.

About key names: the physical keys used for centre and rim hits depend on the player's key bindings. Describing “dk / kd” as valid assumes that those keys are assigned to one centre and one rim input respectively.

Rate-changing mods

stable also applies a rate-changing mod multiplier to the required half-spin threshold. The official legacy-compatible code describes this as DT = 0.75 and HT = 1.5. The table on this page assumes NM; the preview's 25%–150% playback speeds are separate from in-game mods.

Summary
osu!stable's minimum value of 1 is a completion threshold, so a second hit is required to exceed it.
osu!lazer's RequiredHits is the actual input count, so a minimum value of 1 completes after one hit.
